# Pickup codes expire after 72 hours

A parcel left for three days is usually forgotten, and a code that lives forever is a code that leaks. After 72 hours the code stops opening the door; the front desk opens the door with the master key, as it already does for jammed doors, and the parcel stays where it is until then. The check runs at pickup time, so nothing has to sweep the lockers.

A wrong code is still reported as wrong after expiry, so the expiry message never confirms that a guessed code was right.
